# 🛡️ PlotGuard — キャラ設定＆時系列 矛盾チェッカー（プロトタイプ）

長編シナリオや複数人ロールプレイで「このキャラ、過去にどんな設定だっけ？」という
**設定の破綻**を、執筆中にリアルタイムで警告するエディタ拡張のプロトタイプです。

> APIなし・サーバー不要・全データはハードコーディング（`data.js`）。
> `index.html` をダブルクリックするだけで動きます。

## 起動方法
1. `index.html` をブラウザ（Chrome / Edge 等）で開くだけ。
2. ビルド・インストール・通信は一切不要です。

## 画面構成
| エリア | 役割 |
|---|---|
| 左：キャラクターDB | 登録済みキャラの基本設定（STEP1）。「＋登録」で新規追加も可能 |
| 中央：エディタ | シナリオを執筆／貼り付け（STEP2）。矛盾箇所が**黄色くハイライト**（STEP3） |
| 右：整合性レポート | 整合性スコアと、矛盾の詳細＋ワンクリック修正（STEP4） |

## 仕組み（プロトタイプ）
- 本文から `第N章` を読み取り「現在の時間軸」を判定
- キャラごとの設定ルール（`data.js` の `rules`）と照合
  - ⏳ 時系列：居住地・人間関係の前後矛盾
  - 🎭 性格・口調：敬語キャラのタメ口など
  - 📌 設定：利き手・体質（アレルギー）など
- 「修正を適用」で本文を自動置換 → 再解析でスコアが上昇

## 📱 インスタ動画用デモ台本（約20〜30秒）
1. **掴み**：サンプル原稿が開いた状態。黄色ハイライトが5箇所、スコア「60」を見せる
2. 右パネルの「⏳ 太郎はまだ東京にいるはず」をクリック → 該当箇所が光る
3. 「修正を適用」を連打 → ハイライトが消え、スコアが **60 → 92** へ気持ちよく上昇
4. 最後に残る「ハナコとの初対面は第5章」= AIが**自動修正できない指摘も提示**する賢さを見せる
5. 締め：「設定の確認作業から解放。執筆スピードを加速。」

## カスタマイズ
- キャラ・ルール・サンプル原稿はすべて `data.js` を編集するだけ。
- 「＋登録」モーダルの「口調NGワード」に言葉を入れると、その場で口調矛盾ルールが増えます。

## ファイル
```
index.html   画面構造
styles.css   見た目（ダークなクリエイターツール風）
data.js      仮データ（キャラDB / 検出ルール / サンプル原稿）
app.js       解析エンジン・UIロジック
```
